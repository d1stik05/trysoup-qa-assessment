# BUG-008: Unhandled `TypeError` and `yaml.scanner.ScannerError` Tracebacks in `load_config()` on Non-Mapping or Tab-Indented YAML Files `[Traceback]`

## 1. Title
`[Traceback]` `load_config()` and `load_config_from_str()` in `soup_cli/config/loader.py` only check `if raw is None:` after calling `yaml.safe_load()`, crashing with an unhandled `TypeError: SoupConfig() argument after ** must be a mapping, not list` (or `int`/`str`) when the YAML root is not a dictionary, and failing to catch `yaml.YAMLError` (`ScannerError`) on tab indentation or malformed YAML syntax.

## 2. Environment
- **Local Baseline:** Windows 11 (`10.0.26200-SP0`), Python `3.14.2`, `soup-cli==0.72.4`, `pyyaml==6.0.3`
- **Affected Source Files:**
  - `soup_cli/config/loader.py:32-55` (`load_config` and `load_config_from_str`)
  - `soup_cli/commands/config.py:36-45` (`validate` command catches `ValidationError` and `ValueError`, but not `TypeError` or `yaml.YAMLError`)

## 3. Severity
**`Medium`**
**Justification:** `soup config validate` is specifically intended to validate user-edited YAML files and report friendly formatting/schema errors. Instead, passing a YAML list (`- item1`), scalar (`"just_a_string"` or `12345`), or tab-indented YAML file bypasses the friendly error handler in `soup_cli/commands/config.py` and bubbles an unhandled exception (`TypeError` or `yaml.scanner.ScannerError`) up to the top-level CLI crash handler.

## 4. Steps to Reproduce
1. Run `soup --verbose config validate configs/repro_bug008_non_mapping_yaml.yaml` (which contains a YAML list `- item1\n- item2`).
2. Observe the unhandled `TypeError: soup_cli.config.schema.SoupConfig() argument after ** must be a mapping, not list` at `soup_cli/config/loader.py:40`.

## 5. Expected Result
`load_config()` should catch `yaml.YAMLError` and raise a clean `ValueError(f"Invalid YAML syntax: {exc}")`, and verify `if not isinstance(raw, dict): raise ValueError(f"Config root must be a YAML mapping/object, got {type(raw).__name__}")` before unpacking `SoupConfig(**raw)`.

## 6. Actual Result
- **Classification:** `Traceback` (`exit_code = 1`, unhandled `TypeError` / `yaml.scanner.ScannerError`)
- `soup_cli/config/loader.py:40` executes `return SoupConfig(**raw)` on `raw = ['item1', 'item2']`, raising `TypeError`.

## 7. Minimal Reproducing Example
**Command:**
```bash
soup --verbose config validate configs/repro_bug008_non_mapping_yaml.yaml
```

**Minimal YAML ([`../configs/repro_bug008_non_mapping_yaml.yaml`](../configs/repro_bug008_non_mapping_yaml.yaml)):**
```yaml
- item1
- item2
```
