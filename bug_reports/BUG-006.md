# BUG-006: `soup plan` Bypasses `SoupConfig` Pydantic Validation, Succeeding (`exit 0`) and Writing `soup.tfstate` on Invalid Tasks, Negative Epochs/LR, and Conflicting PEFT Flags `[Silent Acceptance]`

## 1. Title
`[Silent Acceptance]` `soup plan` parses `soup.yaml` with raw `yaml.safe_load` instead of `load_config()` / `SoupConfig`, exiting with code `0` (`"No drift — soup.yaml matches previous plan"`) and writing `soup.tfstate` even when `task` is invalid, `epochs` and `lr` are negative, and mutually exclusive `use_dora` + `use_vera` flags are set.

## 2. Environment
- **Local Baseline:** Windows 11 (`10.0.26200-SP0`), Python `3.14.2`, `soup-cli==0.72.4`
- **Affected Source File:** `soup_cli/commands/plan.py` (`plan_cmd` uses raw dictionary lookups on `yaml.safe_load` output without validating against `SoupConfig`)

## 3. Severity
**`High`**
**Justification:** `soup plan` is advertised as the Terraform-style execution planner for `soup-cli` pipelines. Because it completely bypasses `SoupConfig` validation, an invalid configuration that would immediately fail in `soup config validate` (`task: "completely_invalid_task_name"`, `epochs: -100`, `lr: -5.0`, `use_dora: true` + `use_vera: true`) is approved by `soup plan` (`exit 0`) and persisted into `soup.tfstate`.

## 4. Steps to Reproduce
1. Run `soup config validate configs/repro_bug006_plan_bypass.yaml` and confirm that it fails with `exit_code = 1` (`ValidationError` on `task` and `epochs`).
2. Run `soup plan --config configs/repro_bug006_plan_bypass.yaml`.
3. Observe that `soup plan` succeeds with `exit_code = 0` and writes `soup.tfstate`.

## 5. Expected Result
`soup plan` should call `load_config(config_path)` (validating the YAML through `SoupConfig`) before computing the execution plan or writing `soup.tfstate`, and exit with code `1` on schema violations.

## 6. Actual Result
- **Classification:** `Silent Acceptance` (`exit_code = 0`)
- `soup plan --config configs/repro_bug006_plan_bypass.yaml` prints the plan panel (`task=completely_invalid_task_name`, `epochs=-100`, `lr=-5.0`), writes `soup.tfstate`, and exits with code `0`.

## 7. Minimal Reproducing Example
**Command:**
```bash
soup plan --config configs/repro_bug006_plan_bypass.yaml
```

**Minimal YAML ([`../configs/repro_bug006_plan_bypass.yaml`](../configs/repro_bug006_plan_bypass.yaml)):**
```yaml
base: trl-internal-testing/tiny-random-LlamaForCausalLM
task: completely_invalid_task_name
data:
  train: configs/sample_train.jsonl
training:
  epochs: -100
  lr: -5.0
  lora:
    use_dora: true
    use_vera: true
output: ./output_bug006
```
